## Motivation

`@fervqz/just-a-stream` explores how far a tiny stream utility can go while staying predictable and easy to reason about.

The goal was to design an API that is small enough to learn quickly, but flexible enough to compose real data flows.

## Highlights

- Minimal core API focused on composition
- TypeScript-first ergonomics
- Stream creation, transformation, and merging primitives
